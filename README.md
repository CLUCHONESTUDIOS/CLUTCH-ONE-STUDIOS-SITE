# CLUTCH ONE STUDIOS website starter

Responsive static website. No paid theme, build step, tracking scripts, backend, or external dependencies.

## Preview
Open `index.html`, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish free with Cloudflare Pages
1. Create a GitHub repository (for example `clutch-one-studios-site`).
2. Upload the contents of this folder to the repository root; `index.html` must be at the root.
3. In Cloudflare: Workers & Pages → Create → Pages → Connect to Git.
4. Select the repository. Choose **None** for framework preset, leave build command blank, and set build output directory to `/`.
5. Deploy. Cloudflare provides a `pages.dev` address.
6. Later, buy a domain and add it in the Pages project's Custom domains. Follow the DNS instructions. No rebuild is needed to change domains.
